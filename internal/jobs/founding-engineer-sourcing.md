# Founding Engineer — Sourcing List

Target candidate: **senior Python engineer with browser-automation / Playwright experience, curious about MCP and AI agents, comfortable in OSS communities, async-remote friendly.**

Goal of this list: get the JD in front of 1,500–3,000 qualified eyes in the first week, with a 2–4% apply rate.

Channels are grouped by **community fit**, not by traffic. A weak fit channel is a waste of the founder's energy; the channels below are ranked roughly by expected signal-to-noise.

## Tier 1 — Direct community overlap (post first)

These are places where BrowserControl users already hang out. Highest conversion expected.

| # | Channel | What to post | Owner |
|---|---|---|---|
| 1 | **Playwright Discord** (`discord.gg/playwright`) | `#jobs` channel — short version of the JD + link to the full one. Pin a note that BrowserControl is hiring. | Founder |
| 2 | **Model Context Protocol Discord** (`discord.gg/modelcontextprotocol`) | `#hiring` / `#general` — call out that we built one of the most-used MCP servers and we're hiring a founding engineer. | Founder |
| 3 | **FastMCP Discord** (`discord.gg/gJ7sB7`) | `#jobs` — Frame it as: "we use FastMCP, we're hiring the second pair of hands." | Founder |
| 4 | **Hacker News — Who's Hiring (monthly)** | Comment in the monthly "Who's hiring?" thread. Use the HN-friendly format (title, location, comp band, remote, visa). | Founder |
| 5 | **Show HN reply thread** on the BrowserControl launch | Reply to anyone who engaged with the launch. Low-key: "Thanks — and if working on this full-time sounds fun, ping me." | Founder |

## Bonus channels (low effort, opportunistic)

- **X/Twitter** — post from the founder's account and the project account; tag `@playwrightweb`, `@FastMCP`, `@modelcontextprotocol`, `@anthropaboratories`. Ask AI-agent builder community members for a quote or RT.
- **GitHub** — pin an issue titled "We're hiring a Founding Engineer (remote, equity)" on the BrowserControl repo. Many OSS maintainers land here first.
- **LinkedIn** — one post from the founder's account, plus a DM to the top 10 maintainers of MCP servers we've already worked with.
- **AI Engineer World's Fair / MCP Dev Summit / PyCon** — file "we're hiring" lightning talks or sponsor a hiring dinner (Phase 2; not for this role).

## What we explicitly are NOT doing

- **No recruiter cold-DM campaigns.** We tried them in a prior life; the candidates who respond to recruiter DMs at 11pm are not the candidates we want for a founding role.
- **No "AI/ML engineer" generic job boards.** This is a Python + Playwright role, not an ML research role. We will be drowned by people with the wrong profile.
- **No paid Hired.com / Otta / Vettery slots for the first hire.** Save that budget for the Developer Advocate role in Phase 2.

## Operating cadence (week 1)

- **Day 1 (Mon):** Post on HN Who's Hiring + Playwright Discord + MCP Discord.
- **Day 2 (Tue):** r/Python + r/LocalLLaMA + r/MachineLearning.
- **Day 3 (Wed):** FastMCP + Cursor / Cline / Continue.dev Discords + Python Discord.
- **Day 4 (Thu):** GitHub pin issue + LinkedIn post + X thread.
- **Day 5 (Fri):** Triage week-one inbound; decide whether to open Lobsters and WWR on Day 8.

Founder spends **≤ 30 minutes/day** on sourcing during week 1. Sourcing is not the bottleneck — the bar is high enough that inbound volume should not be the constraint.

## Tracking

Each channel gets a unique short link (e.g. `browsercontrol.dev/jobs?src=hn-whos-hiring`) and a row in a simple tracker:

| Channel | Posted? | Date | Applicants | Qualified (passed resume screen) | Notes |
|---|---|---|---|---|---|

Reviewed at the end of week 1 and week 2. Channels with zero qualified applicants get cut.
